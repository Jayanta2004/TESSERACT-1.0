# TESSERACT 1.0 — Esports Society Website (IIT Madras BS)

Official digital platform for **Tesseract**, the Esports Society of the IIT Madras BS Degree program.

> *"Where IITM Students Play, Compete & Connect."*

---

## 🚀 Key Features (PRD v1.0)

- **Authentication & IITM Verification**: Email domain validation (`@study.iitm.ac.in`, `@ds.study.iitm.ac.in`, `@es.study.iitm.ac.in`) with step-by-step student verification.
- **Role Simulation**: Built-in instant role switcher (Guest, Unverified, Verified Student, Admin / Team).
- **Home Page**: Hero section with official branding, live stats (1,250+ students, 24+ tournaments, ₹75,000+ prizes), upcoming tournaments, featured games, and community hubs.
- **Global Announcement Pop-up**: Configurable notice modal with start/end date, image banner, CTA, and admin controls.
- **Games Hub**: Categorized titles (Tactical FPS, Battle Royale, Mind Games, Party/Casual) with official rulebooks and player counts.
- **Events & Tournaments**: Filterable tournament calendar with Google Form registration routing and student credential verification.
- **Native Timed Quiz Platform**: In-house timed MCQ quiz runner (replacing Unstop) with live countdown, question palette, negative marking, auto-submission on timeout, and question explanations.
- **Competitive Leaderboard**: Gold, Silver, and Bronze podium rankings with tie-breaker sorting (*higher score first, then lower completion time*).
- **Society Democratic Polls**: One-vote-per-student verified polling system with animated real-time percentage bars.
- **Minimal Student Profile**: Name, verified IITM email, Gamer Tag, avatar, bio, and tracking for registered events, quiz attempts, and poll votes.
- **Leadership & Council**: Team directory with roles, degree programs, bios, and social links.
- **Admin Control Center**: CMS portal for announcements, tournaments, games, quizzes, polls, and configurable student email domains.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS + Custom Neon Cyber Aesthetic
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Typography**: Audiowide, Orbitron, Inter, JetBrains Mono

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Jayanta2004/TESSERACT-1.0.git

# Navigate to directory
cd TESSERACT-1.0

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
